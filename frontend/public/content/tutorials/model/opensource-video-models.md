视频生成是生成式媒体的" Mount Everest"：模型不仅要会画，还要在几十上百帧之间保持主体、光影、物理的连贯。两年前这还是闭源闭源 Sora 的独舞，如今开源阵营已经能打出有来有回——**Wan、HunyuanVideo、CogVideoX、LTX-Video、Mochi** 各有绝活。

这篇教程带你建立开源视频生成的完整认知：技术难点、各家定位、硬件门槛与上手路径。

## 你将学到

## 视频生成难在哪

- **时空一致性**：一帧画得好不够，主体在 5 秒内不能"融化"，光影要随运动变化，物理（水、布料、碰撞）要大致合理。
- **算力代价**：一段 5 秒 720p 视频相当于上百张图的连续生成，推理开销是生图的百倍量级。
- **数据稀缺**：高质量"视频-文本"配对数据远比图文数据稀缺，这决定了各家的训练路线分化。

## 五款主力模型

### Wan 2.1 / 2.2（阿里）—— 开源综合天花板

当前开源视频的**全能选手**：文生视频、图生视频、首尾帧控制一应俱全，运动幅度与提示词遵循均衡。提供 1.3B（消费级可跑）到 14B（质量档）多个尺寸，diffusers 支持完善，社区工作流最丰富。**如果只选一个入门，选 Wan。**

### HunyuanVideo（腾讯）—— 写实派

写实质量与运镜自然度是强项，人物动作接近"电影感"；同族的混元图像可提供高质量首帧，形成"图→视频"接力。显存门槛偏高，建议 16G 起步（量化）。

### CogVideoX（智谱）—— 轻量亲民

2B 档让消费级显卡（8G 级）真正能跑视频生成，文档与 diffusers 管线质量高，中文提示词友好。质量不及 Wan/混元旗舰档，但**入门、原型、批量低分辨率场景**性价比极高。

### LTX-Video（Lightricks）—— 快者为王

主打**速度**：消费级显卡上接近实时/秒级出片，创作者"快速试错"工作流的首选。质量上限不如旗舰，但迭代速度是另一种生产力。

### Mochi 1（Genmo）—— 运动表现

开源早期的质量标杆之一，大运动幅度场景（体育、舞蹈）表现突出；算力门槛偏高，社区使用率不及 Wan。

## 文生视频 vs 图生视频

生产实践中两者的地位完全不同：

- **文生视频（T2V）**：自由度高，但主体形象、构图不可控，抽卡率高。适合灵感探索。
- **图生视频（I2V）**：先用工图模型（FLUX/Qwen-Image/混元图像）把首帧做到完美，再让视频模型"动起来"。**主体可控、品牌一致、废片率低——生产首选。**

成熟流水线：**生图（首帧）→ 图生视频 → 后期剪辑/配乐**。

## 消费级显卡的现实预期

| 显存 | 现实可用方案 |
|------|--------------|
| 8G | CogVideoX-2B、LTX-Video（低分辨率/短时长） |
| 12–16G | Wan 1.3B / 14B 量化版、多数模型量化档 |
| 24G+ | Wan 14B、混元较高分辨率，批量生产 |

优化三板斧：**量化权重**（fp8/GGUF）、**分块/低分辨率生成再放大**、**云端 GPU 按需跑批**（生视频对"本地常驻"需求其实不高）。

## 上手示例（diffusers，Wan 图生视频）

```python
import torch
from diffusers import AutoencoderKLWan, WanPipeline
from diffusers.utils import export_to_video

pipe = WanPipeline.from_pretrained(
    "Wan-AI/Wan2.2-T2V-A14B",  # 图生视频换对应 I2V 权重
    torch_dtype=torch.bfloat16,
).to("cuda")
# 显存吃紧：pipe.enable_model_cpu_offload()

frames = pipe(
    prompt="无人机视角掠过雪山湖泊，镜头缓慢推进，光线柔和",
    num_frames=81, guidance_scale=5.0,
).frames[0]
export_to_video(frames, "wan.mp4", fps=16)
```

建议从低 `num_frames` 起步调通，再加时长；图生视频把首帧图一并传入（对应 `image=` 参数）。

## 典型场景

- **短视频素材工厂**：生图出首帧（风格统一）→ Wan/混元 I2V 批量动起来 → 剪辑合成。
- **产品演示动画**：产品图 + 局部运动描述（"缓慢旋转"），比三维建模便宜一个量级。
- **概念验证/分镜**：LTX-Video 快速出粗剪，导演确认后再上旗舰模型精修。

## 小结

开源视频生成的格局：**Wan 综合最强、混元最写实、CogVideoX 最亲民、LTX 最快、Mochi 运动派**。生产上记住方法论：**图生视频优先于文生视频，首帧质量决定成片下限，消费级靠量化、生产靠云端**。
