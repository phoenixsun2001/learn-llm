用 SD/FLUX 生成中文内容时你一定体会过那种"差一口气"：提示词翻译腔、图里的中文汉字变天书、审美偏欧美。**国产生图模型**就是为这些问题而生的——中文语义原生理解、图内中文文字渲染、本土审美训练。

这篇教程盘点三款主力国产开源生图模型：阿里的 **Qwen-Image**、快手的 **Kolors**、腾讯的 **HunyuanImage**，以及它们与海外模型的选型差异。

- 图像编辑（指令式改图）能力对比

## 为什么"国产"不是营销词

英文模型处理中文任务有三个结构性短板，国产模型针对性地解决：

1. **语义理解**：中文成语、诗词、品牌名、文化意象（"国潮""水墨""赛博庙会"），原生中文训练的模型理解到位得多。
2. **图内文字**：生成"开业大酬宾"招牌、"福"字春联——这要求模型把汉字当图像画对，Qwen-Image 等在这项上做到了开源领先。
3. **审美与人物**：本土产品线沉淀的审美偏好与东亚人像表现。

## 三强逐个看

### Qwen-Image（阿里）—— 中文与编辑双料旗舰

- **定位**：Qwen 家族的图像生成线，MMDiT 架构，20B 级参数量。
- **强项**：
  - **中文文字渲染**开源标杆：海报、字幕、复杂版式里的汉字正确率显著领先。
  - **原生编辑能力**：Qwen-Image-Edit 支持指令式改图（"把背景换成雪山""把外套改成红色"），不依赖外挂 ControlNet。
  - 中英双语提示词表现均衡。
- **注意**：参数量大，全精度显存门槛高，建议量化使用；许可证总体宽松但逐版本核对。

### Kolors（快手）—— 审美与人像

- **定位**：快手内容生态背后的生图模型开源版。
- **强项**：写实人像质量与本土化审美突出，中文提示词友好；提供不同尺寸变体，消费级显卡可跑。
- **适合**：社交媒体素材、人像类内容生产。

### HunyuanImage（腾讯混元）—— 写实与体系化

- **定位**：混元多模态体系的图像线，与 HunyuanVideo（视频）同族。
- **强项**：写实风格与物理感强；图像→视频工作流里与混元视频衔接顺（先用混元图像出首帧，再转视频）。
- **适合**：追求"图生视频"流水线连贯性的团队。

## 与 SD/FLUX 怎么选

| 需求 | 推荐 |
|------|------|
| 图内中文文字 | Qwen-Image（首选） |
| 中文语义/文化意象 | 国产三家任一，Qwen-Image 综合 |
| 东亚人像/本土审美 | Kolors、混元 |
| 海外风格/英文内容 | FLUX.2、SD3.5 |
| 指令式改图 | Qwen-Image-Edit |
| 图生视频首帧 | 混元图像 + 混元视频 |
| LoRA/社区生态玩法 | SDXL（生态仍是最大） |

## 上手示例（diffusers）

```python
import torch
from diffusers import DiffusionPipeline

pipe = DiffusionPipeline.from_pretrained(
    "Qwen/Qwen-Image", torch_dtype=torch.bfloat16,
).to("cuda")

image = pipe(
    prompt='一张中式茶馆海报，木窗格与暖色灯笼，顶部写"人间烟火"四个行楷大字',
    num_inference_steps=30,
).images[0]
image.save("kolors.png")
```

注意：中文提示词直接写中文，不要翻译成英文再喂；涉及图内文字时把文字内容用引号明确标出，遵循率更高。

## 典型场景

- **本地生活营销图**：Qwen-Image 出带中文文案的招牌/海报初稿，设计师再精修。
- **电商多 SKU 素材**：Kolors 人像 + 换背景编辑，批量出模特图。
- **短视频首帧工厂**：混元图像生成风格统一首帧 → 混元视频批量转视频。

## 小结

国产生图模型的核心价值是"**中文原生**"：语义、文字、审美三件事上海外模型短期补不齐。选型口诀：**文字渲染找 Qwen，人像审美找 Kolors，图接视频找混元**；海外风格与大生态依旧 SD/FLUX。
