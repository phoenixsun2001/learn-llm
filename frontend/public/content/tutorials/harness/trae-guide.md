## 什么是 TRAE Work

TRAE Work 是一款 **AI 原生工作台（AI-native workstation）**，提供网页版、桌面版和移动版三种形态，并设有为不同用户群体设计的 **Work 与 Code 双模式**。它的能力在原有 TRAE IDE SOLO 模式的基础上得到了进一步提升，旨在为用户提供统一、高效、可定制的 AI 协作体验，覆盖从专业开发到日常办公的各类场景。

理解 TRAE Work 的关键，是跳出「它是一个代码编辑器」的固有印象。传统 IDE 只服务开发者、只解决编码问题；而 TRAE Work 把 AI 协作能力延伸到了**更广泛的办公场景**——产品经理写需求、运营做数据分析、市场同学整理资料，都能在 Work 模式下完成；而专业开发者则可以切换到 Code 模式，获得完整的 AI 辅助开发体验。一个工作台，覆盖多种角色。

## 三端形态：网页版、桌面版与移动版

TRAE Work 提供三种形态，覆盖不同场景下的使用需求：

| 形态 | 定位 | 适用场景 |
|------|------|---------|
| **网页版** | 即开即用，无需安装 | 临时任务、跨设备办公、快速体验 |
| **桌面版** | 完整能力，性能更强 | 专业开发、深度编码、大型项目 |
| **移动版** | 随时随地，轻量协作 | 移动办公、消息跟进、内容审阅 |

三端共享统一的账号与数据，你在桌面版开始的任务，可以无缝在网页版或移动版继续。这种「三端协同」的设计，让 AI 协作不再受限于固定工位——通勤路上用手机跟进、办公室用桌面版深度开发、出差时用网页版应急。

### 如何选择

- **不确定是否长期使用**：先从网页版入手，零成本体验
- **以编码为主**：安装桌面版，获得完整的 Code 模式与本地项目能力
- **经常在外**：三端配合，桌面版做主力，移动版做补充

## 双模式：Work 与 Code

双模式是 TRAE Work 区别于传统 IDE 和纯聊天工具的核心设计。它把「非开发用户」和「开发者」两类人群的诉求，统一到了一个工作台里。

### Work 模式：面向所有人的 AI 协作

Work 模式面向**非开发用户**（产品、运营、市场、管理等），提供对话式 AI 协作能力：

- 撰写和润色各类文档、邮件、报告
- 数据整理、表格处理、信息归纳
- 方案策划、头脑风暴、内容创作
- 跨语言翻译、资料检索与总结

在 Work 模式下，你不需要懂代码，用自然语言描述需求，AI 就能帮你完成。这让 AI 的能力真正走出了开发者圈子，赋能到每一个知识工作者。

### Code 模式：面向开发者的 AI 编程

Code 模式面向**专业开发工程师**，提供完整的 AI 辅助开发体验：

- 智能代码补全与生成
- 多文件理解与跨文件重构
- Bug 定位与修复
- 代码审查与优化建议
- 本地项目接入与工程化协作

Code 模式建立在原 TRAE IDE 的能力基础之上，针对真实工程场景做了深度优化，能够理解整个项目的上下文，而不仅是当前文件。

### 模式切换

Work 模式与 Code 模式可以在同一个工作台中自由切换。这意味着一个团队里的不同角色，可以用各自最适合的方式协作：开发者用 Code 模式写实现，产品经理用 Work 模式写需求，两者共享同一个平台。

## SOLO 模式与 TRAE ITA 智能体

SOLO 模式是 TRAE 的招牌能力，其核心是 **TRAE ITA（Intelligent Task Agent）** 智能体——一个支持超长上下文的自主编程智能体。

### TRAE ITA 的核心能力

TRAE ITA 是 SOLO 模式专属的超长上下文智能体，通过多轮交互引导、按计划自动执行和反馈闭环，帮助用户高效完成复杂编码任务。它具备多重能力：

- **超长上下文**：支持百万级 token，可以完整理解超大型项目，覆盖从全局架构到具体函数的完整上下文
- **信息收集与上下文构建**：在动手前主动收集所需信息，构建完整的任务上下文
- **辅助计划与目标拆解**：把复杂目标拆解为可执行的步骤，并按计划推进
- **状态感知与自修复**：执行过程中感知状态，遇到错误能自我修复、持续迭代

### 为什么超长上下文重要

传统 AI 编码工具受限于上下文窗口，只能理解当前文件或一小片代码，处理大型项目时常常「只见树木不见森林」。TRAE ITA 的百万级 token 上下文，让它能一次性吃透整个项目的结构、依赖关系和业务逻辑，做出的修改更符合全局一致性，而不是局部正确但全局冲突。

这种能力在面对**大型重构、跨模块改动、复杂 bug 排查**等长程任务时尤为关键——这些正是传统工具力不从心的场景。

## 安装与快速上手

### 第一步：选择形态并安装

- **网页版**：直接访问 TRAE 官网，登录账号即可使用，无需安装
- **桌面版**：从官网下载对应平台（Windows / macOS）的安装包，按向导完成安装
- **移动版**：在应用商店搜索 TRAE 下载安装

### 第二步：选择模式

首次进入后，根据你的角色选择模式：

- 非开发用户 → 选择 **Work 模式**
- 开发者 → 选择 **Code 模式**（如需深度编程，建议用桌面版）

### 第三步：第一个任务

**Work 模式示例**：

```text
帮我把这份产品需求文档整理成结构化的用户故事列表，
按功能模块分组，每个故事包含「作为…我希望…以便…」格式。
```

**Code 模式示例**（桌面版，打开本地项目后）：

```text
分析 src/api/ 目录下的所有接口，找出缺少错误处理的函数，
并统一补上 try-catch 和错误日志。
```

提交后，TRAE ITA 会自主推进：理解上下文 → 规划步骤 → 执行修改 → 自检验证，你可以在工作台实时观察它的执行过程。

## 与其他工具的对比

| 维度 | TRAE Work | 传统 IDE 插件 | 纯 AI 对话工具 |
|------|-----------|--------------|---------------|
| 产品定位 | AI 原生工作台 | 编码辅助插件 | 通用对话 |
| 目标用户 | 开发者 + 非开发者 | 仅开发者 | 所有人 |
| 上下文能力 | 百万级 token（ITA） | 单文件/小范围 | 对话级 |
| 编程能力 | 强（Code 模式） | 强 | 弱 |
| 办公能力 | 强（Work 模式） | 无 | 中 |
| 多端支持 | 网页/桌面/移动 | 桌面 | 网页/移动 |

TRAE Work 的独特价值在于**「一个工作台，两类用户，三种形态」**的统一——既不是纯粹的编码工具，也不是泛泛的聊天机器人，而是把专业开发与日常办公的 AI 协作整合到一起。

## 最佳实践

1. **按角色选模式**：非开发优先 Work 模式，开发优先 Code 模式，避免用错模式导致体验打折
2. **善用三端协同**：桌面版做主力，网页版做应急，移动版做跟进，让 AI 协作无缝衔接
3. **复杂任务交给 ITA**：大型重构、跨模块改动这类长程任务，交给 TRAE ITA 的超长上下文能力，而非手动逐文件处理
4. **先给上下文再下指令**：无论是 Work 还是 Code 模式，提供充分的背景信息（相关文件、约束、目标）能让产出质量显著提升
