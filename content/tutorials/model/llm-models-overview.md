如果你刚开始接触大语言模型（LLM），多半会被一连串名字绕晕：GPT、Claude、Gemini、GLM、DeepSeek、Qwen、Kimi……它们到底是什么关系？该从哪个入手？

这篇教程不追新版本号，而是从**家族定位**的角度，帮你建立一张稳定的认知地图。具体小版本每年都在更迭（本文以 2026 年中的主流版本为例），但每个家族的"性格"和使用定位是相对清晰的。

## 你将学到

- 区分"闭源 API 模型"和"开源可部署模型"两条主线
- 了解 GPT、Claude、Gemini 三大闭源旗舰 + GLM、DeepSeek 国产主力的定位与特色
- 认识国内其他主流模型（Qwen、Kimi）
- 通过对比表快速判断哪个家族适合哪类场景

## 两条主线：闭源 API 与开源可部署

理解大模型格局，先抓住一条最关键的分歧线：

- **闭源（仅 API/订阅）**：厂商不公开权重，你通过官方 API 或客户端调用。代表是 OpenAI GPT、Anthropic Claude、Google Gemini。优势是省心、性能通常领先、生态成熟；代价是数据出企业、长期依赖供应商、成本随用量浮动。
- **开源（权重可下载）**：模型权重以某种许可证发布，可以本地或私有云部署。代表是智谱 GLM、阿里 Qwen、DeepSeek。优势是数据可控、可微调、长期成本可压低；代价是要自己管算力和运维。

国内市场有个特点：很多模型**同时提供闭源 API 和开源版本**（如 GLM、Qwen、DeepSeek），闭源版往往能力更强、开源版给社区用。这给了你灵活选择的空间。

## 闭源旗舰三巨头

### OpenAI GPT 系列

GPT 是大模型浪潮的起点，也是目前商业化最成熟的家族。它强调**通用能力强、推理与编码均衡、生态（插件、工具调用、Agent）最完整**。GPT 系列把内置"思考"（reasoning）做进了模型本身，多步推理和长任务规划能力突出。

- **定位**：全能型旗舰，闭源
- **典型模型**：GPT-5 系列（当前旗舰 GPT-5.6，另有面向高负载与多模态的档位）
- **适用场景**：通用对话、复杂推理、编码、数据分析、多模态、Agent 编排
- **代价**：仅 API，价格属中高水平

### Anthropic Claude 系列

Claude 以**长文本理解、写作质量、代码与 Agentic（智能体）任务**见长，并且在"可控性"和"安全性"上投入很重。Claude 系列在编码基准和长程任务上长期名列前茅，上下文窗口很大（百万级 token），适合处理整库代码或长文档。

- **定位**：高质量写作 + 编码 + Agent，闭源
- **典型模型**：Claude 5 系列（Opus 旗舰档、Sonnet 性价比档，另有更轻量的 Haiku 档）
- **适用场景**：长文档/代码库处理、技术写作、Agent 自动化、对输出质量要求高的场景
- **代价**：仅 API，Opus 档价格较高

### Google Gemini 系列

Gemini 是 Google 的**全模态**家族，图像、音频、视频与代码的一体化理解是它的招牌，同时在**超长上下文**和 Deep Research 式长程检索上投入很重。对"一个模型同时看文档、读图表、写代码"的场景尤其合适。

- **定位**：全模态 + 超长上下文 + 强检索，闭源
- **典型模型**：Gemini 3 系列（高阶前沿/Pro 档，Flash 轻量高速档）
- **适用场景**：多模态理解、超长文档/视频、深度检索与研究、企业级 Agent
- **代价**：仅 API（部分能力经 Google Cloud / Vertex AI 提供），高阶档价格较高

## 国产主力：GLM 与 DeepSeek

### 智谱 GLM 系列

GLM 是国内最早开源的大模型家族之一，走"**自研 + 开源 + 国产合规**"路线。闭源 API 面向通用与多模态，开源版（支持商用）在国内开发者中装机率很高。近年 GLM 在 Agentic Coding（智能体编程）方向持续强化，并以远低于海外模型的成本提供接近一线的编码能力。

- **定位**：国产开源主力，API + 开源双轨
- **典型模型**：GLM-5 系列（旗舰编码向、GLM-5V 多模态、Flash 轻量高速版）
- **适用场景**：国内合规部署、私有化、中文场景、Agentic Coding、性价比编码
- **优势**：开源商用友好、国产备案顺畅、中文表现好

### DeepSeek 系列

DeepSeek 以"**高性价比 + 强推理**"著称，是国内企业降本与极客圈的热选。它以开源闻名（V3 与 R1 系列全面开源），V4 是最新旗舰，推理与通用能力在开源阵营中位居前列，价格透明。DeepSeek 还配套了开源的 **Harness**（Agent 运行时）生态，让"模型 + 运行脚手架"可以一体自部署。

- **定位**：高性价比推理 + 开源，API + 开源
- **典型模型**：DeepSeek V4 系列（Pro 旗舰档、Flash 轻量档；R 系列为纯推理线）
- **适用场景**：推理密集任务、成本敏感的批量调用、私有化部署、开源 Agent 底座
- **优势**：开源生态活跃、价格低、中文与推理俱佳

## 其他国产主流家族

- **阿里 Qwen（通义千问）**：覆盖密集和 MoE 架构、档位齐全（从端侧小模型到 Max 旗舰），中英双语均衡，开源活跃，适合多档位选型。
- **月之暗面 Kimi**：以超长上下文和中文阅读/写作体验见长，主要面向 C 端和 API 用户，长文档处理是亮点。

## 家族对比表

| 家族 | 开源 | 中文 | 强项 | 典型定位 |
|------|:----:|:----:|------|----------|
| GPT | 否 | 良好 | 通用、推理、多模态、Agent | 闭源全能旗舰 |
| Claude | 否 | 良好 | 长文本、写作、编码、Agent | 高质量闭源 |
| Gemini | 否 | 良好 | 全模态、超长上下文、检索 | 闭源全模态 |
| GLM | 是 | 优秀 | Agentic Coding、性价比 | 国产开源主力 |
| DeepSeek | 是 | 优秀 | 推理、低成本、开源 Agent | 性价比推理 |
| Qwen | 是 | 优秀 | 多档位、双语均衡 | 国产全档位 |
| Kimi | 部分 | 优秀 | 超长上下文 | 长文阅读/写作 |

## 怎么用这张地图

- 想要省心、不差钱、要最好的通用能力 → 闭源旗舰（GPT / Claude / Gemini）。
- 强多模态、超长文档、深度检索 → Gemini（全模态 + 长上下文）。
- 在国内做产品、要合规、要本地部署 → 优先国产开源（GLM / Qwen / DeepSeek）。
- 追求极致性价比与强推理 → DeepSeek（或 GLM / Qwen 的轻量档）。
- 编码与 Agent 自动化是核心需求 → Claude（Opus）或 GLM（Agentic Coding）。
- 处理超长中文文档/合同/代码库 → Claude（长上下文）或 Kimi。

记住：**家族定位比版本号更稳定**。学懂了"性格"，后续每个家族出新品，你都能很快判断它是不是你的菜。

## 小结

大模型世界可以简化成两条主线（闭源 API / 开源可部署）和几个有鲜明性格的家族。闭源三巨头里，GPT 通用全能、Claude 长文与编码、Gemini 全模态与检索；国产阵营中，GLM 主打 Agentic Coding、DeepSeek 主打高性价比推理，Qwen、Kimi 各有所长。掌握这张地图，选型就有了出发点。
