如果你刚开始接触大语言模型（LLM），多半会被一连串名字绕晕：GPT、Claude、GLM、Llama、Qwen、DeepSeek、Kimi……它们到底是什么关系？该从哪个入手？

这篇教程不追新版本号，而是从**家族定位**的角度，帮你建立一张稳定的认知地图。具体小版本每年都在更迭，但每个家族的"性格"和使用定位是相对清晰的。

## 你将学到

- 区分"闭源 API 模型"和"开源可部署模型"两条主线
- 了解 GPT、Claude、GLM、Llama 四大家族的定位与特色
- 认识国内其他主流模型（Qwen、DeepSeek、Kimi）
- 通过对比表快速判断哪个家族适合哪类场景

## 两条主线：闭源 API 与开源可部署

理解大模型格局，先抓住一条最关键的分歧线：

- **闭源（仅 API/订阅）**：厂商不公开权重，你通过官方 API 或客户端调用。代表是 OpenAI GPT、Anthropic Claude、Google Gemini。优势是省心、性能通常领先、生态成熟；代价是数据出企业、长期依赖供应商、成本随用量浮动。
- **开源（权重可下载）**：模型权重以某种许可证发布，可以本地或私有云部署。代表是 Meta Llama、智谱 GLM、阿里 Qwen、DeepSeek。优势是数据可控、可微调、长期成本可压低；代价是要自己管算力和运维。

国内市场有个特点：很多模型**同时提供闭源 API 和开源版本**（如 GLM、Qwen、DeepSeek），闭源版往往能力更强、开源版给社区用。这给了你灵活选择的空间。

## 四大家族速览

### OpenAI GPT 系列

GPT 是大模型浪潮的起点，也是目前商业化最成熟的家族。它强调**通用能力强、推理与编码均衡、生态（插件、工具调用、Agent）最完整**。GPT 系列引入了内置"思考"（reasoning）能力，把多步推理、长任务规划做进了模型本身。

- **定位**：全能型旗舰，闭源
- **典型模型**：GPT-5 系列（含面向高负载任务的 Pro 档位）
- **适用场景**：通用对话、复杂推理、编码、数据分析、Agent 编排
- **代价**：仅 API，价格属中高水平

### Anthropic Claude 系列

Claude 以**长文本理解、写作质量、代码与 Agentic（智能体）任务**见长，并且在"可控性"和"安全性"上投入很重。Claude 系列在编码基准和长程任务上长期名列前茅，上下文窗口很大（百万级 token），适合处理整库代码或长文档。

- **定位**：高质量写作 + 编码 + Agent，闭源
- **典型模型**：Claude 系列（Opus 旗舰档、Sonnet 性价比档，另有更轻量的 Haiku 档）
- **适用场景**：长文档/代码库处理、技术写作、Agent 自动化、对输出质量要求高的场景
- **代价**：仅 API，Opus 档价格较高

### 智谱 GLM 系列

GLM 是国内最早开源的大模型家族之一，走"**自研 + 开源 + 国产合规**"路线。闭源 API 面向通用与多模态，开源版（MIT 许可、支持商用）在国内开发者中装机率很高。近年 GLM 在 Agentic Coding（智能体编程）方向持续强化，并以远低于海外模型的成本提供接近一线的编码能力。

- **定位**：国产开源主力，API + 开源双轨
- **典型模型**：GLM-4 系列（旗舰编码向、Flash 轻量高速版）
- **适用场景**：国内合规部署、私有化、中文场景、Agentic Coding、性价比编码
- **优势**：MIT 开源、商用友好、国产备案顺畅、中文表现好

### Meta Llama 系列

Llama 是"开源大模型"的事实标杆，Meta 的发布直接推动了整个开源生态。Llama 采用 MoE（混合专家）架构，在保持质量的同时降低推理成本。它是很多二次开发、微调、蒸馏项目的底座。

- **定位**：全球开源生态底座
- **典型模型**：Llama 系列（如 Scout 等多档）
- **适用场景**：本地部署、研究、微调/蒸馏基座、英文为主的通用任务
- **注意**：许可证有使用规模条款，大规模商用前需确认；中文表现弱于国产模型

## 国内其他主流家族

- **阿里 Qwen（通义千问）**：覆盖密集和 MoE 架构、档位齐全（从端侧小模型到 Max 旗舰），中英双语均衡，开源活跃，适合多档位选型。
- **DeepSeek**：以"高性价比 + 强推理"著称，V3 与 R1（推理向）系列全面开源，价格透明，是国内极客和企业降本的热门选择。
- **月之暗面 Kimi**：以超长上下文和中文阅读/写作体验见长，主要面向 C 端和 API 用户，长文档处理是亮点。

## 家族对比表

| 家族 | 开源 | 中文 | 强项 | 典型定位 |
|------|:----:|:----:|------|----------|
| GPT | 否 | 良好 | 通用、推理、Agent | 闭源全能旗舰 |
| Claude | 否 | 良好 | 长文本、写作、编码 | 高质量闭源 |
| GLM | 是（MIT） | 优秀 | Agentic Coding、性价比 | 国产开源主力 |
| Llama | 是 | 一般 | 生态底座、可微调 | 全球开源基座 |
| Qwen | 是 | 优秀 | 多档位、双语均衡 | 国产全档位 |
| DeepSeek | 是 | 优秀 | 推理、低成本 | 性价比推理 |
| Kimi | 部分 | 优秀 | 超长上下文 | 长文阅读/写作 |

## 怎么用这张地图

- 想要省心、不差钱、要最好的通用能力 → 闭源旗舰（GPT 系列 / Claude 系列）。
- 在国内做产品、要合规、要本地部署 → 优先国产开源（GLM / Qwen / DeepSeek）。
- 做研究、要自己改模型 → Llama 或 GLM、Qwen 的开源版。
- 处理超长中文文档/合同/代码库 → Claude（长上下文）或 Kimi。
- 编码与 Agent 自动化是核心需求 → Claude 系列 或 GLM 系列。

记住：**家族定位比版本号更稳定**。学懂了"性格"，后续每个家族出新品，你都能很快判断它是不是你的菜。

## 小结

大模型世界可以简化成两条主线（闭源 API / 开源可部署）和几个有鲜明性格的家族。GPT 通用全能、Claude 长文与编码、GLM 国产开源与 Agentic Coding、Llama 全球开源底座；国内还有 Qwen、DeepSeek、Kimi 各有所长。掌握这张地图，选型就有了出发点。
