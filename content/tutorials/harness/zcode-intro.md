## 什么是 ZCode

ZCode 是一个面向 **Long Horizon Task（长程任务）** 的全功能 Agentic Development Environment（智能体开发环境），由 GLM-5.2 官方深度适配。它不是聊天机器人，也不是单纯的代码补全插件——它是一个能在真实工程中自主推进复杂任务、持续迭代的**智能体编程环境**。

与传统「你问一句、AI 答一句」的交互模式不同，ZCode 围绕**任务（Task）**组织工作流：你描述目标，ZCode Agent 规划并执行——读代码、改文件、跑命令、看结果、修正错误——在一个工作台里完成从需求到交付的完整闭环。整个过程中，你可以随时补充上下文、引用文件、调整方向。

ZCode 默认接入 GLM-5.2，同时兼容 GLM Coding Plan、Z.ai 与 BigModel 等多种接入方式，让你可以根据账号和预算灵活选择。

## 核心理念：Long Horizon Task

理解 ZCode 的关键，是理解它为**长程任务**而设计。所谓长程任务，是指那些无法在一两轮对话内完成、需要多步骤推进、中途可能遇到障碍并自我修正的任务，例如：

- 为一个新功能完成「调研代码库 → 设计方案 → 实现 → 自测 → 修复」全流程
- 对一个模块做较大规模的重构，涉及数十个文件
- 排查一个隐蔽的 bug，需要反复假设、验证、缩小范围

对这类任务，传统工具会让用户充当「调度员」，每一步都要手动指挥；而 ZCode 的 Agent 能够**自主地把目标推进到完成**，遇到问题会自行尝试解决，必要时才回头向你确认。这正是它「简单、迅捷、氛围感强」体验的来源——你给出方向，它负责把事情做成。

## 安装与连接

### 第一步：安装 ZCode

访问 ZCode 官方站点 [zcode.z.ai](https://zcode.z.ai) 下载对应平台的安装包。ZCode 提供跨平台支持：

- **macOS**：下载 `.dmg` 安装包，拖入 Applications 即可
- **Windows**：下载安装程序，按向导完成安装
- **Linux**：下载对应发行版包或 AppImage

首次启动后，ZCode 会引导你完成账号连接和初始配置。

### 第二步：连接模型服务

ZCode 默认适配 GLM-5.2，并支持多种接入方式。根据你持有的账号类型选择：

| 接入方式 | 适用场景 | 说明 |
|---------|---------|------|
| **GLM Coding Plan** | 订阅用户 | 按订阅周期使用，适合日常高频开发 |
| **Z.ai** | Z.ai 平台用户 | 通过 Z.ai 账号直接接入 |
| **BigModel** | API 用户 | 按 token 计费，适合需要精细控制用量的场景 |

在设置面板中填入对应的 API Key 或完成 OAuth 登录，ZCode 会自动完成连通性校验。校验通过后，状态栏会显示已连接的模型服务，即可开始使用。

## 你的第一个任务

安装并连接完成后，用一个小任务来熟悉 ZCode 的工作方式。

### 1. 新建任务

在左侧边栏点击「新建任务」（或使用快捷键），在工作台输入你的需求。例如，针对一个已有的项目：

```text
帮我梳理 src/utils/ 目录下的工具函数，把没有 JSDoc 注释的函数补上类型注释，
并修复其中明显的类型问题。
```

### 2. 补充上下文

ZCode Agent 在开始前，你可以引用相关文件作为上下文。在工作区文件树中点击文件即可引用，引用的文件会作为本次任务的背景信息提交给 Agent。

> 小贴士：精准的上下文引用能显著提升 Agent 的工作质量和速度。对于明确知道要处理的文件，主动引用比让 Agent 全局搜索更高效。

### 3. 观察 Agent 执行

提交任务后，ZCode Agent 会自主推进：

1. **感知**：读取你引用的文件、扫描相关代码结构
2. **规划**：分析需要补充注释和修复的位置
3. **行动**：逐个文件修改、写入注释、修正类型
4. **校验**：运行类型检查或构建，确认没有引入新错误

整个过程你可以在工作台实时看到 Agent 的操作步骤、读写了哪些文件、执行了什么命令。

### 4. 验收与迭代

任务完成后，ZCode 会给出变更摘要。你可以：

- 查看具体的文件改动（diff）
- 如果结果不符合预期，直接在对话中追加要求，让 Agent 继续调整
- 满意后接受改动，或回退

这就是 ZCode 的基本工作循环：**你给目标，它负责完成**。

## 小结
